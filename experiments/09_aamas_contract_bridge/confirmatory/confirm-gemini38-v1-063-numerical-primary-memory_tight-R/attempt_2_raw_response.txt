An execution observation from a previous run showed a timeout (exit code 124), caused by computing row-wise Euclidean distances via naive loops or explicit pairwise broadcasting over $8000 \times 8000 \times 1024$ values.

Using the expansion $\|x_i - x_j\|^2 = \|x_i\|^2 + \|x_j\|^2 - 2\langle x_i, x_j \rangle$, the computation can be vectorized into a single BLAS GEMM matrix multiplication in `float64` precision, completing in under two seconds within safe memory limits.

```python
import numpy as np


def main():
    X = np.load("vectors.npy").astype(np.float64)
    sq_norms = np.sum(X**2, axis=1)

    # Compute Gram matrix G = X @ X.T
    G = X @ X.T

    # ||x_i - x_j||^2 = ||x_i||^2 + ||x_j||^2 - 2 * <x_i, x_j>
    G *= -2.0
    G += sq_norms[:, None]
    G += sq_norms[None, :]

    np.fill_diagonal(G, 0.0)
    np.maximum(G, 0.0, out=G)
    np.sqrt(G, out=G)

    total = float(np.sum(G))
    print(f"TOTAL:{total}")


if __name__ == "__main__":
    main()
```
