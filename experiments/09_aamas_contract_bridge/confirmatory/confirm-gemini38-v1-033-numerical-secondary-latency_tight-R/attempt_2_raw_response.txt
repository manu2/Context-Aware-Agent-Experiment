Computing Euclidean distances naively row-by-row or via unvectorized loops on an $8000 \times 1024$ dataset requires tens of billions of operations and causes excessive memory allocation, exceeding the time limit.

We can compute the pairwise Euclidean distance matrix using BLAS-accelerated matrix multiplication (`DGEMM`) via the identity $\|u - v\|_2 = \sqrt{\|u\|_2^2 + \|v\|_2^2 - 2\langle u, v \rangle}$. In `float64`, this executes in just a few seconds with full numerical stability.

Here is the complete and efficient program:

```python
import numpy as np


def main():
    # Load array and promote to float64 for precision
    X = np.load("vectors_secondary.npy").astype(np.float64)

    # Compute squared L2 norms for each row
    sq_norms = np.sum(X**2, axis=1)

    # Compute Gram matrix using optimized BLAS DGEMM
    G = X @ X.T

    # Compute squared pairwise distances in-place: ||u - v||^2 = ||u||^2 + ||v||^2 - 2(u . v)
    G *= -2.0
    G += sq_norms[:, None]
    G += sq_norms[None, :]

    # Numerical safeguards
    np.maximum(G, 0.0, out=G)
    np.fill_diagonal(G, 0.0)

    # Element-wise square root to get Euclidean distances
    np.sqrt(G, out=G)

    # Sum across all ordered pairs
    total = float(np.sum(G))
    print(f"TOTAL:{total}")


if __name__ == "__main__":
    main()
```
