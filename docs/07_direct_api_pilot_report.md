# Direct-API Pilot Report (Protocol v1.1)

**Execution date:** 2026-08-27  
**Scope:** One clean A/D pair for each of three direct provider API models. This is an
execution report, not a manuscript update and not a statistical analysis.

## Protocol and provenance

All included artifacts were generated by
`experiments/06_replication/run_replication.py` using `RUN_MANIFEST.json`
protocol `1.1-frozen`. The runner verified the frozen prompt hashes, the
`vectors.npy` SHA-256, and the pinned macOS/Python/NumPy environment before every
generation. Each included directory contains the unmodified provider response,
extracted `script.py`, and `metadata.json` with its model configuration, timestamp,
execution environment, and profile.

The included paired IDs are:

| Model | Blind (A) | Telemetry (D) |
|---|---|---|
| Claude Opus 5 | `opus_rep02_A` | `opus_rep02_D` |
| GPT-5.6-Sol | `gpt_rep01_A` | `gpt_rep01_D` |
| Gemini 3.7 Flash | `gemini_rep01_A` | `gemini_rep01_D` |

`opus_rep01_A` was accidentally invoked twice before the runner had a write-once
guard. Its earlier response was overwritten, so that pair is retained but excluded
from this report and from any later inference. See
[`LAUNCH_ANOMALIES.md`](../experiments/06_replication/audit/LAUNCH_ANOMALIES.md).

## Results

All six included scripts exited successfully, produced a total within the preset
relative-error tolerance, and completed in under 10 seconds. `MaxRSS` is the
observed OS process peak resident set size collected with macOS
`RUSAGE_CHILDREN`; `<=128 MB` is therefore an observed-RSS classification, **not**
evidence that a cgroup or container memory limit was enforced in this pilot.

| Model | A MaxRSS (MB) | D MaxRSS (MB) | RSS change | A wall (s) | D wall (s) | Correct A/D | Observed `<=128 MB` A/D |
|---|---:|---:|---:|---:|---:|---|---|
| Claude Opus 5 | 206.02 | 107.48 | -47.8% | 0.8300 | 0.3405 | yes / yes | no / yes |
| GPT-5.6-Sol | 113.06 | 65.83 | -41.8% | 0.5960 | 0.3457 | yes / yes | yes / yes |
| Gemini 3.7 Flash | 306.38 | 124.91 | -59.2% | 1.1614 | 0.4391 | yes / yes | no / yes |

## Descriptive code comparison

All three blind scripts already used a blocked pairwise-distance computation.
The telemetry condition did not establish a uniform switch from an infeasible eager
algorithm to a streaming one. Instead, in these three draws it selected lower-memory
variants:

- Claude changed from a float64, 1024-row block approach to float32 with a
  512-row block and in-place centering.
- GPT changed from float64, 1024-row blocks to float32, 512-row blocks.
- Gemini retained 1000-row batching but changed its working representation from
  float64 to float32.

This is useful pilot evidence that the disclosed limit can influence memory-related
implementation choices. It is not sufficient to estimate an across-model effect,
test significance, or claim general first-pass cgroup survivability. The planned
remaining predeclared pairs should be analyzed only after they are all complete;
direct-API data must not be pooled with the archived proxy pilot or historical
generated-script artifacts.
