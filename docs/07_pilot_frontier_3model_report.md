**Date:** August 2026

**Status:** Exploratory proxy pilot; `paper_draft.md` is unmodified.

**Execution context:** Three isolated Antigravity subagent configurations generated one response for each condition. The legacy directory labels are retained only to locate artifacts; they do not identify provider API models.

## 2. Exploratory Interpretation

In this one-pair-per-configuration proxy pilot, Configurations 1 and 2 selected lower-memory strategies under Condition D and passed the 128 MB threshold; Configuration 3 did not. This is a descriptive observation about these archived subagent outputs, not a general claim about model behavior or a statistical conclusion.
